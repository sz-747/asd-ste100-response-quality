# Working Log

## Changelog

### 2026-10-03

- Reframed the skill from a writing-style preset to a response-quality methodology.
- Decoupled linguistic, structural, evidence, terminology, and minimalism checks.
- Added a project-style skill folder with a public playbook, requirements, design, tests, and prompt.
- Kept the user-level `SKILL.md` as the discovery entrypoint.

## Lessons learned

- ASD-STE100 is a strong linguistic check, but it is not a complete answer-quality model.
- Shorter text can be less useful when it removes prerequisites, evidence, limits, or recovery steps.
- Review modules should be selected by task instead of applied mechanically to every response.
